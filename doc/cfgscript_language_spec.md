# cfgscript 语言规范（Language Specification）

## 1. 引言

### 1.1 语言定位
`cfgscript` 是一种 **面向配置文件的领域专用语言（DSL）**，用于在配置生成阶段引入受控的脚本能力。

该语言 **不是通用编程语言**，其目标是：
- 描述配置之间的关系
- 生成最终的静态配置文本
- 保持结果可读、可调试、可复现

### 1.2 设计原则
- **配置优先**：最终结果始终是纯配置文本
- **受控能力**：不支持函数、跳转、递归
- **确定性**：相同输入必然产生相同输出
- **可诊断**：错误精确到文件与行号

---

## 2. 源文件结构

### 2.1 文件编码
- UTF-8 文本
- 行结束符：LF 或 CRLF

### 2.2 行类型
每一行属于以下之一：
- 空行
- 注释行
- 指令行（以 `%` 开头）
- 配置行（KV）

---

## 3. 注释

```
# comment
; comment
```

- 注释行在所有阶段被忽略
- 注释不可出现在行中间（不支持行尾注释）

---

## 4. 标识符（Identifier）

```
IDENT ::= [A-Za-z_][A-Za-z0-9_]*
```

- 区分大小写
- 用于宏名、变量名、循环变量

---

## 5. 宏与替换

### 5.1 宏定义

```
%define IDENT value
```

- `value` 为文本
- 在存储前会进行宏替换

### 5.2 宏取消

```
%undef IDENT
```

### 5.3 宏替换

```
${IDENT}
```

- 替换为当前符号表中的值
- 未定义宏替换为空字符串

---

## 6. 表达式语言

### 6.1 基本类型
- 整数（64 位有符号）
- 字符串（仅用于比较）

### 6.2 运算符

#### 算术
```
+  -  *  /  %
```

#### 比较
```
==  !=  <  <=  >  >=
```

#### 逻辑
```
!  &&  ||
```

#### 括号
```
( expression )
```

### 6.3 运算符优先级（高 → 低）

1. 一元 `! + -`
2. `* / %`
3. `+ -`
4. `< <= > >= == !=`
5. `&&`
6. `||`

### 6.4 内建函数

```
defined(IDENT)
```

- 若 IDENT 已定义 → 1
- 否则 → 0

---

## 7. %set 指令

```
%set IDENT expression
%set IDENT = expression
```

- 对 expression 求值
- 结果以字符串形式存入符号表

---

## 8. 条件指令（%if）

```
%if expression
    ...
%elif expression
    ...
%else
    ...
%endif
```

### 8.1 语义规则
- expression 为真（非零）则进入对应分支
- 同一 if 结构中仅一个分支生效
- 支持嵌套

---

## 9. 循环指令（%for）

### 9.1 范围循环

```
%for IDENT in expr1 .. expr2
    ...
%endfor
```

- expr1、expr2 在进入循环前求值
- 步进恒为 +1
- 若 expr1 > expr2，循环体不执行

### 9.2 列表循环

```
%for IDENT in item1,item2,item3
    ...
%endfor
```

- 每个 item 作为文本注入循环变量

### 9.3 作用域规则
- 循环变量在循环体内有效
- 离开循环后恢复原值（如存在）

---

## 10. 文件包含（%include）

```
%include "path/to/file.cfg"
%include <path/to/file.cfg>
```

- 相对路径以当前文件所在目录为基准
- 最大嵌套深度有限制（实现相关）

---

## 11. 配置行（KV）

```
key = value
key : value
```

- key 不做语义解释
- value 为最终文本
- 所有宏在预处理阶段已展开

---

## 12. 预处理输出

- 所有 `%` 指令被移除
- 输出为纯配置文本
- 可选择附带源位置注释：

```
# file.cfg:12
key = value
```

---

## 13. 错误处理

### 13.1 错误类型
- 语法错误
- 表达式错误
- 控制结构不匹配
- I/O 错误

### 13.2 错误信息格式
```
file:line: description
```

---

## 14. 未定义行为

以下情况行为未定义或直接报错：
- 除零 / 模零
- 未闭合的 %if / %for
- 未识别的指令
- 指令出现在非法位置

---

## 15. 语言约束与非目标

- 不支持函数定义
- 不支持递归
- 不支持用户自定义类型
- 不支持运行期执行

---

## 16. 总结

cfgscript 是一种 **确定性、可诊断、工程友好** 的配置生成语言，其语言能力刻意限制在“生成配置”这一目标内，避免演化为不可控的通用脚本语言。
